# Hi, I'm Aslam

I build practical tools for civic transparency, community support, and education, with a focus on Puducherry, India.

My projects combine Python, TypeScript, React, React Native, document processing, and AI-assisted workflows. I care about traceable evidence, privacy, and making complex information easier to use.

## Projects

| Project | What I've built | Current stage |
| --- | --- | --- |
| [Puduvai Voice](https://github.com/aslam58/puduvai-voice) · [Live pilot](https://puduvaivoice.online) | Civic reporting in English, Tamil, and Hindi, with location-based reports, moderation, issue tracking, and AI-assisted administrator review. | Deployed pilot; readiness checks continue. |
